# Help App Africa images

All WebP, at most 1600px wide, original aspect ratio kept. Every frame on the
site is 16:10 and screens are fitted inside it (never cropped), so any shape
works; keep `width`/`height` in `help-app-africa.html` matching the file.

| File | Size | Where | Shows |
| --- | --- | --- | --- |
| `apps.webp` | 960×720 | Lead image, work card | Client home, splash and provider home |
| `admin.webp` | 1440×1024 | After block 02 | Admin dashboard, flat |
| `login-admin.webp` | 1600×1200 | After block 03 | Admin login and dashboard, angled tablets |
| `client-home.webp` | 1600×1200 | Pair after block 04, left | Client home, single phone |
| `admin-framed.webp` | 1600×1200 | Pair after block 04, right | Admin dashboard in a tablet frame (same screen as admin.webp) |

To replace one, keep the filename and update its `width`/`height` if the
aspect ratio changes.
